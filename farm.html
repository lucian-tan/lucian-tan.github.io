Redesigning data for smarter aquaculture decisions

Improving a data analytics web platform for new agri-tech forecasting and analysis needs

Overview

An agri-tech startup needed a more robust data entry and analytics platform to better serve new business needs. Working with various stakeholders, I led the user research and design for a comprehensive overhaul of the core product, connecting multiple features into a cohesive ecosystem to yield more accurate insights and applicable information for new target users.

Through revamping existing features and introducing new products, we reduced the delivery time for consultants to complete custom assignments through adoption of web features and streamlined implementation of new analyses with a modular design system.

Business need

Customers found the clunky interface discouraging for data uploads, while its outdated design weakened sales pitches and limited R&D’s ability to showcase new data visualisations.

Goal

Streamline the data input and analysis experience for users, while refreshing the interface to attract new customers.

Result

Existing customers expressed greater satisfaction with the user experience of the product and sales teams reported better impressions from new customers.

Integration

Re-organising products into a shared ecosystem

Business need

The product lacked relevance to the needs of a new target market. Sales, product, and R&D needed integrated solutions to showcase more actionable data insights.

The products' fragmented workflows and components hindered user adoption, while technical debt in the codebase slowed engineering efficiency.

Goal

Establish a more intuitive system for users to input and organise various data types, so as to obtain more accurate insights. Achieving this elevates the product to deliver insights with superior accuracy and real-world relevance.

Result

Self-service customers generated insights more efficiently, while consultants leveraged the system to automate tasks and reduce delivery time. Additionally, a new design system lowered development efforts.
